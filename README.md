# ICT374 study notes

Study material for ICT374 (Operating Systems and Systems Programming) at Murdoch.

## What's in here

- `ICT374-Lecture-Slides/` has the slides for Topics 1 to 11 (`ICT374Topic01.pdf` to `ICT374Topic11.pdf`), the sample exam paper, and the review lecture. HOWEVER, the review lecture is from Semester 2 2025 (but I doubt things have changed if it hasn't been updated since last year.)
- `Textbooks/` has the two unit textbooks as PDFs: Stallings, *Operating Systems: Internals and Design Principles* (9th ed.), and *Advanced Programming in the UNIX Environment* (3rd ed.). Each one has a description file next to it. The Stallings file lists the chapter page ranges, which helps because the PDF page numbers don't match the printed ones.

## The exam

The format below comes from the Semester 2 2025 review slides.

- 2 hours plus 10 minutes reading time, closed book, no calculators.
- 100 marks across 26 questions. All 11 topics can come up, and the marks split roughly 50/50 between OS theory and Unix programming.
- Part I is 20 multiple choice questions, 1 mark each, answered on a separate answer sheet in blue or black pen. It covers OS theory and Unix programming concepts.
- Part II is 6 questions worth 80 marks, written on the paper. Questions 1 to 3 (40 marks) are Unix programming in C or pseudo-code, using system calls like fork, wait, read, write and the socket calls. Questions 4 to 6 (40 marks) are OS theory.
- If you can't remember a system call's syntax, you can use your own notation and add a note on what it does and what parameters it takes.
